# Формулограф

Тренажёр формул по физике: приложение задаёт вопрос, формулу пишешь от руки, оно проверяет запись прямо на устройстве и ведёт статистику ошибок по разделам.

Открыть: https://grizot1109-dotcom.github.io/Ratnick/

На iPhone: открой ссылку в Safari → «Поделиться» → «На экран Домой».

- `index.html` — приложение
- `recognizer.js` — распознавание рукописной формулы (алгоритм $P + разбор дробей и корней)
- `glyphs.js` — образцы символов из однолинейных шрифтов Hershey
- `sw.js`, `manifest.webmanifest` — работа без интернета и установка на экран
